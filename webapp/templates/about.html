API Documentation

Complete reference for the Novel Reader REST API

Base URL: http://localhost:8000/

Search & Discovery

Search Novels

Search for novels across all supported sources

GET /api/search?q={query}&sep={true|false}
Parameters:
ParameterTypeRequiredDescription
qstringYesSearch query (novel title, author, keywords)
sepbooleanNoIf true, groups results by source (default: false)
Example Request:
curl "http://localhost:8000/api/search?q=%E6%B4%AA%E8%8D%92&sep=false"
Example Response:
{
  "grouped": false,
  "results": [{"title": "洪荒：我開局打造鴻蒙金榜", "url": "https://ixdzs8.com/book/123", "author": "作者名", "latest_chapter": "Chapter 500", "cover_url": "https://...", "source": "ixdzs8"}]
}
Get Home Feed

Get hot novels and recommendations from sources

GET /api/feed?source={source}&page={number}
Parameters:
ParameterTypeRequiredDescription
sourcestringNoSpecific source (ixdzs8, shuhaige, biquge, ttkan, xbiquge)
pageintegerNoPage number for pagination (default: 1)

Novel Information

Get Novel Details

Retrieve complete novel metadata including chapter list

GET /api/novel-info?url={novel_url}
Example Request:
curl "http://localhost:8000/api/novel-info?url=https%3A%2F%2Fixdzs8.com%2Fbook%2F123"
Example Response:
{
  "title": "洪荒：我開局打造鴻蒙金榜",
  "author": "作者名",
  "status": "Ongoing",
  "description": "故事简介...",
  "cover_url": "https://...",
  "chapters": [{"title": "Chapter 1", "url": "https://..."}],
  "source": "ixdzs8"
}
Extract Chapter Content

Extract clean chapter text from a chapter URL

GET /api/chapter?url={chapter_url}
Example Response:
{
  "title": "Chapter 1: Rebirth",
  "content": "The primordial world!\n\nA mysterious island...",
  "confidence": 0.95,
  "url": "https://..."
}

Translation Engine

List Available Engines
GET /api/v1/novel/engines
Available Engines:
Free (No API Key)
  • google_free - Google Translate
  • bing_free - Bing Translator
  • mymemory_free - MyMemory
  • pons_free - PONS Dictionary
  • linguee_free - Linguee
  • libre_free - LibreTranslate
Premium (API Key Required)
  • gemini_premium - Google Gemini AI
  • openai_premium - OpenAI GPT-4o
  • deepl_premium - DeepL Pro
  • microsoft_premium - Microsoft Translator
  • baidu_premium - Baidu Translate
  • yandex_premium - Yandex Translate
Translate Chapter
POST /api/v1/novel/translate-chapter
Request Body:
{
  "chapter_content": "这是要翻译的中文文本。",
  "engine_selection": "google_free",
  "user_keys": {"gemini_key": "AIzaSy...", "openai_key": "sk-proj-..."},
  "custom_prompt": "Translate this wuxia novel maintaining martial arts terminology"
}
Batch Translate Paragraphs
POST /api/v1/novel/translate-batch
Vercel Serverless Note: For hobby tier (10s timeout), use batch translation in your frontend to send smaller chunks (3-5 paragraphs per request).

Rate Limits & Best Practices

Rate Limits
  • Self-hosted: No limits (respect source websites' terms)
  • Vercel Free Tier: 10-second timeout per request
  • Vercel Pro Tier: Up to 5 minutes per request
Best Practices
  • Use batch translation endpoint for large chapters on Vercel
  • Implement client-side caching to reduce API calls
  • Add delays between requests when scraping
  • Use cover images from cache when available
  • Respect robots.txt of source websites
